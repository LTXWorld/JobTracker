# JobView 用户指导功能设计文档

## 📖 概述

JobView 用户指导功能是一个面向新用户的交互式引导系统，采用PPT演示风格，帮助用户快速了解和掌握系统的核心功能。该功能在用户首次登录时自动触发，并可通过帮助按钮随时访问。

## 🎯 设计目标

### 核心目标
- **降低学习成本**：通过直观的演示帮助用户快速上手
- **突出核心功能**：重点展示系统的差异化优势
- **提升用户体验**：减少新用户的困惑和流失
- **增强产品价值感知**：让用户了解系统的完整功能体系

### 设计原则
- **简洁直观**：每页内容聚焦单一功能点
- **交互友好**：支持多种导航方式（鼠标、键盘、触摸）
- **视觉美观**：现代化UI设计，保持与系统整体风格一致
- **智能显示**：避免过度打扰，合理控制显示频率

## 🏗 系统架构

### 技术栈
- **前端框架**：Vue 3 + Composition API
- **UI组件**：Ant Design Vue
- **样式方案**：Scoped CSS + 响应式设计
- **状态管理**：Pinia + localStorage
- **构建工具**：Vite

### 核心组件结构
```
src/
├── components/
│   └── UserGuide.vue          # 主要指导组件
├── utils/
│   └── userGuide.ts           # 状态管理工具类
└── components/
    └── AppLayout.vue          # 集成层
```

## 🧩 功能模块设计

### 1. UserGuide.vue - 核心展示组件

**职责**：
- PPT式多页内容展示
- 页面切换动画和导航
- 响应式布局适配
- 键盘和触摸交互支持

**关键特性**：
- 7页精心设计的指导内容
- 流畅的页面切换动画
- 进度条和页面指示器
- 快速跳转到相关功能

**技术亮点**：
```vue
<!-- 动态进度条 -->
<div class="progress-fill" :style="{ width: `${(currentSlide + 1) / totalSlides * 100}%` }"></div>

<!-- 键盘事件监听 -->
const handleKeydown = (event: KeyboardEvent) => {
  switch (event.key) {
    case 'ArrowLeft': prevSlide(); break
    case 'ArrowRight': nextSlide(); break
    case 'Escape': finishGuide(); break
  }
}
```

### 2. UserGuideManager - 状态管理类

**职责**：
- 管理用户指导状态（已看过、跳过次数）
- 提供智能显示判断逻辑
- 本地存储数据持久化
- 开发调试工具

**核心方法**：
```typescript
class UserGuideManager {
  static shouldShowGuide(): boolean        // 智能判断是否显示
  static markGuideCompleted(): void        // 标记为已完成
  static resetGuideState(): void          // 重置状态（调试用）
  static getGuideState(): UserGuideState  // 获取当前状态
}
```

**智能显示逻辑**：
- 新用户：自动显示
- 已看过：不再自动显示
- 跳过3次以上：不再自动显示
- 手动触发：始终可用

### 3. 集成层设计

**AppLayout.vue 集成点**：
- 头部帮助按钮：`<a-button @click="showUserGuide">`
- 状态监听：`watch(() => authStore.isLoggedIn)`
- 延迟显示：`setTimeout(() => showGuide.value = true, 1000)`


### 2. 关键设计决策

**进度条位置优化**：
- 问题：原设计进度条位置随内容宽度变化
- 解决：使用绝对定位固定在右侧
- 代码：`position: absolute; right: 32px; top: 50%;`

**内容溢出处理**：
- 问题：第六页内容过多导致标题被遮挡
- 解决：调整slide布局为`align-items: flex-start`
- 优化：减少边距，允许内容区域滚动

**响应式适配**：
```css
@media (max-width: 768px) {
  .guide-container { height: 95vh; }
  .features-grid { grid-template-columns: 1fr; }
  .progress-bar { width: 150px; }
}
```

### 3. 交互设计

**多种导航方式**：
- 鼠标点击：按钮和指示器
- 键盘操作：左右箭头、ESC键
- 触摸手势：适配移动端

**反馈机制**：
- 页面切换动画：300ms缓动
- 按钮hover效果：颜色和位移变化
- 进度条实时更新：视觉进度感知

### 2. 生命周期管理

**组件挂载**：
```typescript
onMounted(() => {
  document.addEventListener('keydown', handleKeydown)
})

onUnmounted(() => {
  document.removeEventListener('keydown', handleKeydown)
})
```

**状态监听**：
```typescript
watch(() => authStore.isLoggedIn, (isLoggedIn) => {
  if (isLoggedIn) {
    checkAndShowGuide()
  }
}, { immediate: true })
```

## 🚀 使用场景

### 1. 新用户引导
**场景**：用户首次注册并登录系统
**流程**：
1. 完成注册/登录
2. 页面加载完成1秒后自动显示指导
3. 按步骤了解各功能模块
4. 完成指导并跳转到相应功能

### 2. 功能发现
**场景**：老用户想了解新功能或重新学习
**流程**：
1. 点击右上角帮助按钮（?）
2. 重新浏览完整指导内容
3. 直接跳转到感兴趣的功能模块

### 3. 客户演示
**场景**：向潜在客户演示系统功能
**流程**：
1. 重置指导状态：`resetUserGuide()`
2. 登录演示账号自动触发指导
3. 通过指导展示核心功能和价值

### 4. 用户培训
**场景**：团队内部培训或客户培训
**流程**：
1. 使用指导作为标准化培训材料
2. 结合实际操作演示各功能
3. 新员工可自主完成基础功能学习
