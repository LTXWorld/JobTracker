# 2. 用户分析

## 2.1 目标用户群体

**主要用户**：
- 正在求职的职场人士和应届毕业生
- 同时投递多个岗位的求职者
- 希望自动化管理求职流程的效率型用户

**用户特征**：
- 熟悉基本的邮箱操作
- 有一定的网络安全意识
- 追求高效率的求职管理
- 对数据隐私有一定要求

## 2.2 用户使用场景

**场景1：多邮箱管理**
用户同时使用多个邮箱（Gmail、QQ邮箱、163邮箱等）接收招聘邮件，需要在一个平台统一管理。

**场景2：实时监控**
用户希望系统自动监控邮箱，当收到面试邀请等重要邮件时立即收到通知。

**场景3：自动状态更新**
用户希望系统能够根据邮件内容自动识别并更新对应求职申请的状态。

**场景4：面试提醒**
用户希望系统能够提取邮件中的面试时间信息并设置智能提醒。
