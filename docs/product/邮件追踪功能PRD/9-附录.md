## 9.1 术语表

| 术语 | 定义 |
|------|------|
| **IMAP** | Internet Message Access Protocol，互联网消息访问协议 |
| **POP3** | Post Office Protocol 3，邮局协议第3版 |
| **OAuth2.0** | 开放授权标准，允许用户让第三方应用访问该用户在某一网站上存储的私密的资源 |
| **Cron** | Unix/Linux系统下的定时任务执行器 |
