# 5. 技术架构

## 5.1 系统架构设计

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   前端界面      │    │   API网关       │    │   后端服务      │
│   Vue.js        │◄──►│   Gateway       │◄──►│   Go Services   │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                                       │
                       ┌─────────────────┐             │
                       │   消息队列      │◄────────────┤
                       │   Redis/Queue   │             │
                       └─────────────────┘             │
                                                       │
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   邮箱服务商    │◄──►│   邮件同步器    │◄──►│   数据库        │
│   Gmail/QQ等    │    │   IMAP Client   │    │   PostgreSQL    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## 5.2 核心技术栈

**前端技术**：
- Vue.js 3 + TypeScript
- Element Plus UI组件库
- Pinia状态管理
- Axios HTTP客户端

**后端技术**：
- Go语言 + Gin框架
- GORM数据库ORM
- Redis缓存和消息队列
- Cron定时任务调度

**数据库设计**：
- PostgreSQL主数据库
- Redis缓存层
- 数据库连接池优化

**第三方服务**：
- 邮箱服务商API
- 云存储服务
- 监控和日志服务

## 5.3 数据库设计

**核心数据表**：
- `user_mailboxes`：用户邮箱配置表
- `mail_events`：邮件事件记录表
- `mail_sync_logs`：邮件同步日志表
- `mail_parse_rules`：邮件解析规则表
