# JobView 系统功能概览

> 最后更新：2024年9月14日
> 版本：v2.0

## 🎯 系统概述

JobView 是一个现代化的求职进程管理系统，采用 Vue 3 + Go 的前后端分离架构，为求职者提供一站式的求职信息管理解决方案。系统经过全面性能优化，查询响应时间提升 84-89%，支持 100-200 并发用户。

## 🏗️ 技术架构

### 前端技术栈
- **框架**: Vue 3.4 + TypeScript 5.5
- **UI 组件库**: Ant Design Vue 4.2.6
- **状态管理**: Pinia 3.0.3
- **路由管理**: Vue Router 4
- **图表库**: Vue ECharts
- **构建工具**: Vite 7.1
- **拖拽排序**: VueDraggable

### 后端技术栈
- **语言**: Go 1.24.5
- **Web 框架**: Gin + Gorilla Mux
- **数据库**: PostgreSQL 15
- **认证**: JWT (支持自动刷新)
- **ORM**: 原生 SQL + 连接池优化
- **文件存储**: 本地存储 + 静态资源服务

### 性能优化
- **数据库**: 7个关键索引，智能连接池，查询优化
- **并发处理**: 支持 100-200 并发用户（提升 400-900%）
- **响应时间**: 查询响应时间减少 84-89%
- **前端优化**: 组件懒加载，虚拟滚动，状态缓存

## 📱 核心功能模块

### 1. 用户认证与安全
- ✅ **用户注册**
  - 实时用户名/邮箱可用性检查
  - 密码强度实时评估与规则提示
  - 服务条款与隐私政策确认
- ✅ **用户登录**
  - JWT Token 认证（24小时有效期）
  - 自动刷新 Token（30天刷新期）
  - 记住登录状态
  - 5次失败后5分钟锁定机制
- ✅ **个人中心**
  - 个人资料编辑
  - 头像上传与管理
  - 密码修改
  - 账户统计信息

### 2. 投递记录管理
- ✅ **投递创建**
  - 完整的投递信息录入
  - 公司属性分类（央国企/私企）
  - 面试信息记录
  - HR联系方式管理
- ✅ **批量操作**
  - Excel/CSV 批量导入（支持10000+条记录）
  - 批量状态更新
  - 批量删除
  - 批量导出

### 3. 状态跟踪系统
- ✅ **22种投递状态**
  - 基础状态：已投递、简历筛选中/未通过
  - 笔试状态：笔试中/通过/未通过
  - 面试状态：一面/二面/三面/HR面（各含中/通过/未通过）
  - 最终状态：待发offer、已收到offer、已接受offer、已拒绝、流程结束
- ✅ **状态流转管理**
  - 状态历史记录
  - 状态停留时长统计
  - 状态变更日志
  - 智能状态分类（进行中/已通过/已失败）

### 4. 视图展示模式
- ✅ **看板视图** (Kanban Board)
  - 拖拽式状态管理

  - 搜索高亮定位

- ✅ **时间线视图** (Timeline)

  - 排序选项（日期/公司/状态）
  - 分页加载
- ✅ **表格视图**
  - 传统表格展示

## 🚀 部署方案

### 支持的部署方式
1. **本地开发环境**: Docker Compose 一键启动
2. **云服务器部署**: Nginx + Systemd + PostgreSQL
3. **容器化部署**: Docker + Kubernetes（规划中）
4. **CI/CD**: GitHub Actions 自动部署

### 系统要求
- **服务器**: Ubuntu 22.04 / CentOS 8+
- **内存**: 最低 2GB，推荐 4GB+
- **存储**: 最低 20GB
- **数据库**: PostgreSQL 14+
- **Node.js**: 18+ (前端构建)
- **Go**: 1.20+ (后端编译)
