# 🎵 音乐播放器 - 用户指南

> 为您的求职之路添加美妙背景音乐

## ✨ 功能概述

JobView内置了精美的音乐播放器，提供放松的背景音乐，让求职管理变得更加愉悦。

## 🎨 界面设计

### 胶片唱盘设计
- **🎵 唱片图标**: 精美的旋转胶片唱盘
- **📍 位置**: 界面左下角，不影响主要操作
- **🎛️ 控制面板**: 可展开/收起的播放控制器

### 播放控制
- **⏮️ 上一首**: 切换到上一首歌曲
- **⏯️ 播放/暂停**: 控制音乐播放状态
- **⏭️ 下一首**: 切换到下一首歌曲
- **🔊 音量控制**: 滑块调节音量大小
- **📊 进度条**: 显示播放进度，支持拖拽跳转

## 🚀 使用指南

### 基础操作
1. **展开播放器**: 点击左下角的唱片图标
2. **开始播放**: 点击播放按钮开始音乐
3. **调节音量**: 使用音量滑块调节大小
4. **切换歌曲**: 使用上一首/下一首按钮
5. **收起播放器**: 再次点击唱片图标收起

### 高级操作
- **拖拽进度**: 在进度条上点击或拖拽跳转
- **快捷键**: 空格键暂停/播放（当焦点在播放器上）
- **音量快调**: 滚轮调节音量（鼠标悬停在播放器上）

## ⚙️ 设置与配置

### 音量设置
- **默认音量**: 50%（防止突然的大声音）
- **音量范围**: 0% - 100%
- **静音功能**: 音量设为0即为静音

### 播放模式
- **顺序播放**: 按歌单顺序循环播放
- **自动播放**: 页面加载时不自动播放
- **循环模式**: 播放完最后一首回到第一首

## 🔧 自定义音乐

### 添加音乐文件
1. 将音乐文件放入 `frontend/public/music/` 目录
2. 支持格式：MP3、WAV、OGG、M4A等
3. 文件名建议使用英文或数字

### 更新播放列表
修改播放器组件中的歌单配置：
```javascript
const playlist = [
  {
    id: 1,
    title: "歌曲名称",
    artist: "艺术家",
    src: "/music/song-file.mp3"
  }
  // 添加更多歌曲...
]
```

## ❓ 常见问题

### Q: 音乐无法播放？
**A**: 检查步骤：
1. 确认音频文件存在且路径正确
2. 检查文件格式是否支持
3. 确认浏览器音频权限
4. 查看浏览器控制台错误信息

### Q: 音质不佳或有杂音？
**A**: 优化建议：
1. 使用高质量音频文件（320kbps MP3或以上）
2. 检查音频文件是否损坏
3. 调整系统音量和播放器音量比例

### Q: 播放器影响性能？
**A**: 性能优化：
- 音频文件使用压缩格式
- 避免同时加载过多音频文件
- 及时暂停不需要的播放
