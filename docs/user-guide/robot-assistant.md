## ✨ 功能概述

银月是JobView的智能AI助手，具备三种智能回答模式：

### 🧠 智能模式分类
1. **📚 内置知识库** - 专业求职问题（快速、准确）
2. **🤖 LLM大模型** - 通用知识和情感咨询（智能、全面）
3. **🔄 智能路由** - 自动选择最佳回答方式

## 🎯 使用指南

### 进入银月助手
1. 点击界面右下角的银月头像
2. 进入欢迎界面，查看功能卡片
3. 点击输入框开始对话

## ⚙️ LLM模型配置

### 本地模式（推荐）
使用Ollama本地部署：

```bash
# 安装Ollama
brew install ollama  # macOS
# 或下载安装包: https://ollama.ai

# 启动服务
ollama serve

# 下载模型
ollama pull qwen2.5-coder:latest
```

### 云端模式
支持OpenAI API等云端服务（需要配置API密钥）

## ❓ 常见问题

### Q: 银月无法回答我的问题？
**A**: 检查问题类型：
- 求职相关 → 尝试不同表达方式
- 通用问题 → 确认LLM服务是否启动
- 查看控制台是否有错误信息

### Q: LLM响应很慢或失败？
**A**: 优化建议：
- 检查Ollama服务状态
- 尝试更轻量的模型（如qwen2.5:3b）
- 确保网络连接稳定

### Q: 如何获得更好的回答质量？
**A**: 提问优化：
- 提供更多上下文信息
- 使用准确的术语
- 避免过于宽泛的问题

## 🔧 故障排除

### 检查服务状态
```bash
# 测试Ollama连接
curl http://localhost:11434/api/tags

# 查看已安装模型
ollama list
```

### 常见错误解决
1. **连接失败** → 重启Ollama服务
2. **模型未找到** → 重新下载模型
3. **响应超时** → 调整超时配置
