## ❓ 常见问题

### 账号相关
**Q: 忘记密码怎么办？**
A: 点击登录页面的"忘记密码"链接，通过邮箱重置密码。

**Q: 如何修改邮箱？**
A: 在个人中心→个人信息中修改邮箱地址。

### 功能使用
**Q: 如何批量删除投递记录？**
A: 在列表页面选中多条记录，点击批量操作→删除。

**Q: 提醒功能不工作？**
A: 检查浏览器通知权限，确认提醒时间设置正确。

### 数据问题
**Q: 统计数据不准确？**
A: 刷新页面重新加载数据，检查筛选条件设置。

**Q: 导出的数据不完整？**
A: 确认导出范围设置，检查筛选条件。
