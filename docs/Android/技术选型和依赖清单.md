# JobView Android 技术选型和依赖清单

## 📱 核心技术栈

### 主框架
- **React Native**: `0.76.5` (推荐使用最新稳定版)
  - 支持 New Architecture (Fabric + TurboModules)
  - 更好的性能和内存管理
  - 支持 TypeScript 开箱即用

### 开发语言
- **TypeScript**: `5.6+`
  - 严格类型检查
  - 更好的代码提示和错误检测
  - 大型项目维护性

### UI 组件库
- **Tamagui**: `1.120+`
  - 高性能的跨平台 UI 库
  - 支持 Material Design 3
  - 优秀的主题化支持
  - 树摇优化，减少包体积

### 状态管理
- **Redux Toolkit**: `2.5+`

## 📋 安装指南

### 1. 环境准备

```bash
# 安装 Node.js (推荐使用 nvm)
nvm install 18
nvm use 18

# 安装 React Native CLI
npm install -g @react-native-community/cli

# 验证环境
npx @react-native-community/cli doctor
```

### 2. 项目初始化

```bash
# 创建项目
npx @react-native-community/cli@latest init JobViewMobile --template react-native-template-typescript

# 进入项目目录
cd JobViewMobile

# 安装依赖
npm install

# 安装 iOS 依赖 (仅 macOS)
cd ios && pod install && cd ..
```

### 3. 配置 Tamagui

```bash
# 安装 Tamagui
npm install @tamagui/core @tamagui/config @tamagui/animations-react-native

# 配置主题和动画
npm install react-native-reanimated react-native-svg
```

### 4. 数据库配置

```bash
# 安装 WatermelonDB
npm install @nozbe/watermelondb

# Android 配置
npm install @nozbe/sqlite-adapter

# 生成数据库模型
npm run codegen
```

### 5. 运行项目

```bash
# 启动 Metro bundler
npm start

# 运行 Android (新终端)
npm run android

# 运行测试
npm test
```
