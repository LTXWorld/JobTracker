# JobView Kotlin 客户端低保真交互稿

> 版本：v0.1（2025-02-15）  
> 目标平台：Android（Kotlin + Jetpack Compose）  
> 覆盖范围：底部导航、求职进程、数据统计、添加投递、我的/个人信息

## 1. 全局布局与导航

### 1.1 底部导航结构

```
┌────────────────────────────────────────────┐
│ App Bar（标题/筛选/用户入口）              │
├────────────────────────────────────────────┤
│ 主内容（根据 Tab 切换）                    │
├────────────────────────────────────────────┤
│ Progress ▢   Stats ▢   ⊕ Add   Profile ▢  │
└────────────────────────────────────────────┘
```

- 四个 Tab：`进程（Progress）`、`统计（Stats）`、`添加（Add）`、`我的（Profile）`。
- 中间 `Add` 为凸起 FAB，优先级最高，点击弹出多步表单。
- 每个 Tab 使用 `Navigation Compose` 独立 Back Stack，确保状态保活。

### 1.2 常用交互规范
- **筛选条**：位于 App Bar 底下，包含搜索、过滤 Chips、排序按钮，可滚动隐藏。
- **加载状态**：Skeleton + `CircularProgressIndicator`；空态展示「暂无数据」+ CTA。
- **错误状态**：Illustration + 重试按钮，Toast/Snackbar 显示详细原因。
- **反馈**：状态更新/新增成功使用 Snackbar，附「撤销」按钮。

## 2. 求职进程（Progress Tab）

### 2.1 折叠列表结构

```
┌─Filter Bar: [搜索][状态][日期]────────────────────┐
│                                                  │
│ ▼ 已投递 (42)                                    │
│   ┌Card─────────────────────────────────────┐    │
│   │公司+职位    | 状态标签 | 更新时间        │    │
│   │地点/薪资                                 │    │
│   │提醒信息 / 备注                            │    │
│   └──────────────────────────────────────────┘    │
│   …（LazyColumn）…                                │
│ ▲ 面试阶段 (18)                                   │
│   （折叠状态仅显示统计与展开按钮）                │
└──────────────────────────────────────────────────┘
```

- 默认展开最近活跃状态，其余折叠。
- 卡片操作：点击进入详情；长按进入多选模式（顶部显示已选数量，底部浮出操作栏：移动状态/删除/提醒）。
- 快捷操作：右滑 == 快速更新状态；左滑 == 添加提醒。
- 分页：每个状态单独分页，滚动到底触发 `Load More`。
- 空态：显示「该状态暂无投递」并提供「添加投递」按钮。

### 2.2 交互流程
1. **状态筛选**：点击状态 Chip，调出底部筛选面板（多选状态、流程类型）。
2. **批量状态更新**：
   - 长按卡片进入多选 → 选择记录 → 点击底部「移动状态」→ 弹出状态列表 → 选择目标状态 → 请求成功后弹 Snackbar。
3. **提醒设置**：卡片中的提醒图标支持快速启停；若需要编辑具体时间则跳转提醒详情。

## 3. 添加投递（中央 FAB）

### 3.1 多步表单布局

```
Step Indicator: 1 / 4  （基础信息）
┌─────────────────────────────────────┐
│ 公司名称 [输入框]                   │
│ 职位名称 [输入框]                   │
│ 申请日期 [Date Picker]             │
│ 求职周期 [下拉]                     │
│ 当前状态 [下拉]                     │
│ 企业属性 [单选：央企/私企/外企…]     │
└─────────────────────────────────────┘
< 上一步            下一步 >
```

- 步骤：基础信息 → 职位与地点 → 联络与提醒 → 面试与备注。
- 头部展示进度条，底部固定操作栏（上一页/下一页）。
- 草稿：返回或关闭时弹出对话框是否保存草稿，默认自动保存。
- 验证：必填项失焦即校验，Step 切换前阻止并高亮提示。

### 3.2 提交反馈
- 成功：全屏确认页面或 Snackbar，自动跳转回 Progress 并定位到对应状态。
- 失败：对话框/Toast 提示，支持重试或保存草稿。

## 4. 数据统计（Stats Tab）

### 4.1 布局

```
┌──Period Tabs: [7天][30天][全部]────────────────────┐
│ KPI Cards:                                        │
│  ┌总投递 120┐  ┌Offer 5┐  ┌面试 18┐  ┌转化率 12%┐ │
├───────────────────────────────────────────────────┤
│ 趋势图（折线/柱状）                                │
├───────────────────────────────────────────────────┤
│ 漏斗图                                            │
├───────────────────────────────────────────────────┤
│ 状态分布（饼图/条形图）                            │
└───────────────────────────────────────────────────┘
```

- 顶部 Tabs 控制统计区间，支持左右滑动切换。
- 每块区域均有空态/错误态占位；图表在加载时显示 Skeleton。
- KPI 卡支持点击跳转关联页面（如跳至进程筛选）。

### 4.2 交互
- 长按图表可显示 tooltip。
- 下拉刷新触发重新请求 `/analytics/mobile`。
- “分享”按钮导出当前视图（后续迭代）。

## 5. 我的（Profile Tab）

### 5.1 页面划分

1. **个人资料卡**：头像、昵称、邮箱、编辑按钮。
2. **账号与安全**：密码修改、登录设备列表（预留）、登出。
3. **我的简历**：列表展示简历卡片，点击进入编辑；每卡包含名称、更新时间、默认标识。
4. **偏好设置**：主题模式（系统/亮/暗）、语言、状态排序。
5. **其他**：反馈、关于、调试工具入口。

### 5.2 简历编辑流程
- 进入简历详情后，使用列表/Accordion 展示各分区（教育、经历、技能……）。
- 每个分区内可添加/删除条目，使用 BottomSheet 编辑。
- 保存时调用 `PUT /me/resumes/{id}`；若设为默认需追加确认提示。
