# JobView 用户使用指南

> 最后更新：2024年9月14日
> 适用版本：v2.0

## 🎯 快速开始

### 第一步：注册账号

1. 访问 JobView 首页，点击右上角「注册」按钮
2. 填写注册信息：
   - **用户名**：3-20个字符，支持字母、数字、下划线
   - **邮箱**：用于接收通知和找回密码
   - **密码**：至少8位，需包含大小写字母、数字和特殊字符
3. 阅读并同意《服务条款》和《隐私政策》
4. 点击「立即注册」完成注册

💡 **提示**：系统会实时检查用户名和邮箱是否可用，并显示密码强度指示。

### 第二步：登录系统

1. 输入用户名和密码
2. 可选择「记住登录状态」保持30天免登录
3. 点击「登录」进入系统

⚠️ **注意**：连续5次登录失败将锁定账号5分钟。

### 第三步：完善个人资料

1. 登录后点击右上角头像进入「个人中心」
2. 上传个人头像（支持 JPG/PNG，最大2MB）
3. 填写真实姓名和联系电话
4. 点击「保存」更新资料

## 📝 投递管理

### 创建投递记录

#### 方式一：手动创建
1. 点击主页「新增投递」按钮
2. 填写投递信息：
   - **基础信息**：公司名称、职位、投递日期
   - **职位详情**：薪资范围、工作地点、职位描述
   - **联系信息**：HR姓名、电话、邮箱
   - **面试安排**：面试时间、地点、类型
3. 点击「提交」保存记录

#### 方式二：批量导入
1. 点击「批量导入」按钮
2. 下载 Excel 模板
3. 按模板格式填写数据
4. 上传 Excel 文件
5. 确认字段映射
6. 点击「开始导入」

💡 **提示**：支持导入10000+条记录，系统会自动验证数据并提示错误。

### 管理投递状态

#### 状态类型说明
- **基础状态**：已投递、简历筛选中/未通过
- **笔试状态**：笔试中/通过/未通过
- **面试状态**：一面/二面/三面/HR面（各含进行中/通过/未通过）
- **最终状态**：待发offer、已收到offer、已接受offer、已拒绝、流程结束

#### 更新状态方法
1. **快速更新**：在列表中点击状态标签快速切换
2. **详情更新**：进入详情页更新并添加备注
3. **拖拽更新**：在看板视图中拖动卡片到目标状态列
4. **批量更新**：选择多条记录统一更新状态

### 搜索和筛选

1. **快速搜索**：在搜索框输入公司或职位关键词
2. **高级筛选**：
   - 按状态筛选
   - 按公司筛选
   - 按日期范围筛选
   - 按薪资范围筛选
3. **排序选项**：
   - 按投递日期排序
   - 按公司名称排序
   - 按当前状态排序

## 🎨 视图模式

### 看板视图（推荐）

看板视图以卡片形式直观展示投递状态：

1. **查看模式**：
   - 「进行中」标签：显示所有进行中的投递
   - 「已失败」标签：显示所有失败的投递
2. **操作方式**：
   - 拖拽卡片更改状态
   - 点击卡片查看详情
   - 双击卡片快速编辑
3. **搜索定位**：输入关键词自动高亮并定位到对应卡片

### 时间线视图

时间线视图按时间顺序展示投递历程：

1. **时间轴展示**：以时间线形式展示所有投递
2. **筛选功能**：支持多维度筛选
3. **分页加载**：大数据量时自动分页

### 表格视图

传统表格视图提供最全面的信息展示：

1. **完整信息**：一次性显示所有字段
2. **列操作**：支持排序、筛选、隐藏列
3. **批量操作**：选择多行进行批量处理

## 🔔 提醒功能

### 设置提醒

1. 在投递详情页点击「设置提醒」
2. 选择提醒类型：
   - **面试提醒**：面试前1小时/1天提醒
   - **跟进提醒**：自定义时间提醒跟进
3. 设置提醒时间和备注
4. 点击「保存」激活提醒

### 管理提醒

1. 点击顶部铃铛图标进入「提醒中心」
2. 查看所有待办提醒
3. 标记已完成或删除提醒
4. 设置提醒偏好（邮件/站内通知）

## 📊 数据统计

### 查看统计报表

1. 点击左侧菜单「数据统计」
2. 查看关键指标：
   - **总览数据**：总申请数、活跃申请、成功率
   - **状态分布**：饼图展示各状态占比
   - **趋势分析**：折线图展示投递趋势
   - **阶段分析**：柱状图展示各阶段通过率

### 数据导出

1. 点击「导出数据」按钮
2. 选择导出格式（Excel/CSV）
3. 选择导出字段
4. 设置筛选条件
5. 点击「开始导出」
6. 下载生成的文件

## 📄 简历管理

### 创建简历

1. 点击「简历管理」→「新建简历」
2. 选择简历模板
3. 填写各模块信息：
   - 基本信息
   - 教育经历
   - 工作经验
   - 项目经历
   - 技能证书
4. 实时预览效果
5. 点击「保存」

### 导出简历

1. 选择要导出的简历
2. 点击「导出PDF」
3. 选择导出选项：
   - 是否包含照片
   - 是否包含联系方式
4. 下载PDF文件

- 选择时间线紧凑/舒适模式

### 提醒规则

- 设置自动提醒规则
- 配置提醒频率（每日/每周/自定义）
- 选择提醒方式（邮件/站内）

### 数据管理

进入「设置」→「数据管理」：
- 导出所有数据备份
- 清理历史数据
- 账号注销申请

## 🔧 常见问题

### Q1: 忘记密码怎么办？
**A**: 点击登录页「忘记密码」，输入注册邮箱，系统会发送重置链接到邮箱。

### Q2: 如何批量修改投递状态？
**A**: 在表格视图中勾选多条记录，点击顶部「批量操作」→「更新状态」。

### Q3: 导入Excel失败怎么处理？
**A**:
1. 检查Excel格式是否符合模板要求
2. 确保必填字段都已填写
3. 日期格式使用 YYYY-MM-DD
4. 状态值必须与系统定义一致

### Q4: 提醒没有收到怎么办？
**A**:
1. 检查提醒设置是否正确
2. 确认邮箱地址无误
3. 查看垃圾邮件文件夹
4. 检查浏览器通知权限

### Q5: 如何删除投递记录？
**A**:
- 单个删除：在详情页点击「删除」按钮
- 批量删除：勾选多条记录后点击「批量删除」

### Q6: 数据会自动保存吗？
**A**: 是的，所有操作都会实时保存到服务器，无需手动保存。

### Q7: 支持手机访问吗？
**A**: 支持，系统采用响应式设计，手机浏览器可正常访问使用。

### Q8: 如何联系客服？
**A**: 点击页面底部「帮助中心」或发送邮件至 support@jobview.com

## 💡 使用技巧

### 高效管理技巧

1. **善用标签和备注**：为每个投递添加详细备注，方便后续跟踪
2. **及时更新状态**：收到面试通知立即更新，保持数据实时性
3. **设置提醒**：重要面试设置多个提醒时间点
4. **定期导出备份**：每周导出数据备份，防止意外丢失

### 快捷键操作

- `Ctrl/Cmd + N`：新建投递
- `Ctrl/Cmd + S`：保存当前编辑
- `Ctrl/Cmd + F`：快速搜索
- `Ctrl/Cmd + E`：导出数据
- `ESC`：关闭弹窗

### 最佳实践

1. **信息完整性**：尽可能填写完整的投递信息
2. **及时跟进**：设置跟进提醒，主动联系HR
3. **数据分析**：定期查看统计报表，优化投递策略
4. **简历优化**：根据不同职位调整简历内容
