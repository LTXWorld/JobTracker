# 11. 后续建议
- 建议先建立 API 契约文档（可在 `docs/api/` 使用 OpenAPI），统一前后端、扩展、移动端的路径和负载结构。

- 编写数据库迁移基线脚本，淘汰 `init.sql`，并在 CI 中增加迁移验证。
- 在 `frontend` 与 `backend` 添加关键路径集成测试，覆盖状态回滚、邮件事件确认、简历附件上传等场景。
