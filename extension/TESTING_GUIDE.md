# Chrome扩展程序测试指南

## 前置准备

### 1. 确认后端服务运行
- ✅ JobView后端已在 http://localhost:8010 运行
- 测试API健康检查：`curl http://localhost:8010/api/v1/health`

### 2. 确认前端服务运行
```bash
cd /Users/lutao/GolandProjects/jobView/frontend
npm run dev
```
前端应该在 http://localhost:3001 运行

## 测试步骤

### 第一步：登录JobView平台
1. 打开浏览器访问 http://localhost:3001
2. 使用测试账号登录：
   - 用户名：testuser
   - 密码：TestPass123!
3. 确认登录成功

### 第二步：完善简历信息
1. 登录后，点击"我的简历"菜单
2. 填写个人信息：
   - 姓名
   - 邮箱
   - 电话
   - 城市
   - 求职意向
   - 教育背景
   - 工作经验
3. 保存简历信息

### 第三步：测试扩展程序
1. 点击Chrome右上角的JobView扩展图标
2. 检查弹窗显示：
   - 连接状态：应显示"已连接"
   - 简历数据：应显示数据完整度
   - 当前网站：显示支持状态

### 第四步：测试自动填充
1. 访问测试网站（以下任选其一）：
   - https://www.zhaopin.com
   - https://www.51job.com
   - https://www.zhipin.com

2. 进入简历编辑或职位申请页面

3. 观察页面：
   - 应该出现蓝色浮动按钮"自动填充"
   - 或者点击扩展图标，点击"自动填充"按钮

4. 点击自动填充：
   - 观察表单字段是否被正确填充
   - 检查姓名、邮箱、电话等基础信息

## 常见问题排查

### 1. 连接失败
- 检查后端服务是否运行
- 检查端口8010是否正确
- 查看控制台错误信息

### 2. 未检测到简历数据
- 确认已登录JobView平台
- 确认已填写简历信息
- 尝试点击"同步数据"

### 3. 自动填充不工作
- 检查当前网站是否在支持列表
- 查看页面是否有表单元素
- 检查控制台是否有错误

## 调试技巧

### 查看背景脚本日志
1. 打开 chrome://extensions/
2. 找到JobView扩展
3. 点击"背景页面"或"Service Worker"
4. 查看控制台输出

### 查看内容脚本日志
1. 在目标网站页面
2. 打开开发者工具（F12）
3. 查看Console标签
4. 过滤"JobView"相关日志
