# JobView Chrome Extension - 测试指南

## 🚀 快速开始

### 1. 加载插件到Chrome

1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `extension` 文件夹
5. 插件将出现在扩展程序列表中

### 2. 准备测试环境

确保JobView后端服务正在运行：
```bash
# 启动后端服务
cd backend
go run cmd/main.go

# 启动前端服务
cd frontend
npm run dev
```

### 3. 登录并完善简历

1. 访问 http://localhost:3001
2. 登录您的JobView账号
3. 进入「我的简历」页面
4. 完善基本信息、教育经历、工作经历等

## 🔧 调试技巧

### 1. 查看控制台日志
- 右键插件图标 → 「检查弹出式窗口」
- F12 开发者工具 → Console标签

### 2. 检查后台服务日志
- 访问 `chrome://extensions/`
- 点击插件的「服务工作进程」链接

### 3. 调试Content Script
- F12 开发者工具 → Sources标签
- 查找 `content.js` 文件

### 4. 查看存储数据
- F12 开发者工具 → Application标签
- 左侧选择 Extension Storage
